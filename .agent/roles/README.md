# Role 入口

选择 [NORMAL](normal/README.md)、[COMPLEX](complex/README.md)、[DESIGN](design/README.md) 或 [Program](program/README.md)，打开对应完整 Prompt，复制整个文件到独立 Agent Session。

原平铺 `roles/<Role>Agent.md` 路径仅属于历史版本；按原 Task.task_type 选择同名角色的新路径，机器 Role 枚举不变，历史 Task/Handoff 不改写。Collector/Assembler 属于 program；Architect/DocsSpecWriter 属于 design；Analyst 属于 complex。旧 Deliverer 仅见 [legacy](legacy/DelivererAgent.md)，不用于新任务。
