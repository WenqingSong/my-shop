# 可选宿主业务规则模板

此模板不是接入必需文件，不自动创建或覆盖宿主根 AGENTS.md。框架通用指令唯一入口为 `.agent/AGENTS.md`；协作规范、Role 与 Schema 不在宿主重复定义。

仅当 Owner 明确要求建立新的宿主业务规则时，由 Agent 根据真实项目填写语言/目录、业务不变量、资源权威、构建测试和服务约定；原文件存在时读取并保留，不用本模板替换。未知事实请求 Owner。已有根文件的过时 Workflow 入口仅在明确授权融合其具体差异后修正，不改变业务规则或历史 Evidence。

框架架构与辅助顾问材料分别为 `.agent/specs/Architecture.md`、`.agent/assistant-context.md`。
