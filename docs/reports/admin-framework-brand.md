# Framework 管理端品牌改造

基线：`feat/phase2-admin-frontend` / `6666f642980ea85ce280e7cb0cfb2582f8ca84d3`。
实现分支：`feat/admin-framework-brand`。
品牌参考：`framework-station/logo` / `d86814bab376dacdef940d67543ca2015eeb3c66`。

## 品牌与页面

- 复制正式 v5 几何图形与 Precision A 候选字标；SVG 路径不改动，按 URL 引入，适配 `/console/` 子路径。A 用于本次产品应用，不变更母品牌仓库的候选状态。
- 新增 `BrandIdentity.vue` 与 `style/brand.scss`。以黑白、暖灰、细边框和系统字体统一后台，功能状态保留文字和颜色。
- 登录页采用双区域品牌介绍与账号表单；窄屏收为单栏。登录校验阶段也防止重复提交；模拟模式显示演示凭据，真实模式不显示。
- 重做导航品牌区、页脚和启动占位，调整侧栏宽度。移除模板演示通知，保留真实账户与搜索入口。
- 工作台优先展示今日支付金额、订单及新增用户，统一图表色板；移除父子组件重复的首次加载。
- 商品列表突出名称、价格、状态；移除没有真实数据的库存占位列，规格库存继续在详情查看。
- 订单列表前置状态；商品、订单列表使用现有 KeepAlive 能力保留筛选和页码，返回时重新查询并恢复滚动位置。
- 商品查询与商品/订单详情补全增加请求令牌，避免过期响应覆盖当前筛选。
- 商品表单增加固定保存区，校验错误定位首个字段。
- 全站共用表格、筛选栏、分页、表单、弹窗及抽屉样式，更新库存、退款、营销、内容和权限页面的业务文案。保留退款人工确认、活动不可回读、角色已有权限不可查询、筛选范围等关键限制。
- 支持深色模式和系统减少动态效果。无额外品牌开场等待。

## 预览与启动

本地预览：`http://localhost:8849/console/`，显式启用项目原有 MSW 模拟数据。演示账号 `admin`，密码 `mock-password`。演示操作不代表真实业务联调。

真实接口开发使用 `admin/` 中已有默认配置，默认请求 `http://127.0.0.1:8000`。

```sh
cd admin
pnpm install --frozen-lockfile
pnpm dev
```

演示预览：

```sh
VITE_MOCK_ENABLED=true pnpm dev --port 8849
```

新配置使用 `surgecart-brand-` 存储命名空间，使品牌默认布局不受旧模板设置影响；不更改认证 token 存储机制。

## 刷新加载与自动主题补充（2026-11-10）

根据 Owner 后续要求，启动加载改为调用品牌仓库原版 `motion-v13.js`（文件逐字节复制，已与来源比对），不再仅使用静态 Logo。

- `public/brand/` 提供主题预解析、官方动画播放器和启动生命周期。启动层独立于 Vue 挂载点；应用准备好后调用官方 640ms 消散退出。没有强制等待 5.4 秒完整循环。
- 页面等待超过 20 秒或初始化失败时，取消动画、恢复正式静态图形并展示重试按钮，避免永久加载。播放器资源异常时保留内联 SVG。
- 自定义 `v-loading` 使用同一播放器，120ms 内完成的请求不闪现遮罩；请求结束或组件卸载时取消播放器、移除遮罩与计时器。路由切换增加局部加载反馈，失败导航同步清理。
- 所有现有异步按钮补充品牌 loading 插槽；详情页采用品牌图形与骨架。系统减少动态效果由官方播放器与 CSS 同时尊重。
- 默认主题为“跟随系统”，页面首次绘制前解析系统偏好，登录页、启动层、后台、局部加载和图表共用同一状态。用户可手动选择并保存浅色、深色或跟随系统；跨标签页同步。
- 去除模板中重复的主题监听，图表使用明确管理的 ECharts 生命周期；主题变化重新应用轴线、标签、提示框和分隔线颜色，卸载时释放观察器和实例。
- 修正横向导航遗留的根路径 `/logo.svg` 引用。静态 script URL 交由 Vite 添加一次 `/console/` 前缀，避免 `/console/console/`。
